# Pokédex Field Scanner

A responsive Pokédex web app powered by the public PokéAPI.

## Live preview

[Open the Pokédex Field Scanner](https://saikiranreddykarla.github.io/pokedex/pokedex.html)

## Features

- National Pokédex search with detailed Pokémon data
- Filters for type, region, and generation
- Combinable filters and responsive browsing
- Official artwork and base-stat summaries

## Run locally

Open `outputs/pokedex.html` in a modern browser. An internet connection is required for Pokémon data and artwork.
